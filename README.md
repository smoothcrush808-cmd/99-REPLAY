# 99-REPLAY — 관점방 리플레이

나인구 「관점방」(2024-09-29 ~ 12-06) 리딩 기록을 BTC 심리차트 위에서 **읽고 · 리플레이**하는 페이지.
원본 차트: https://smoothcrush808-cmd.github.io/BTC/

## 처음 여는 세션(클라우드)은 여기부터

1. `docs/00_공통설계.md` — 전체 틀·데이터 형식·시각 기준·공개 범위(**A안: 글·장부는 암호화본만**)
2. `docs/02_차트_작업지시.md` — 이 저장소에서 할 일
3. `docs/sample_posts.json` · `docs/sample_trades.json` — **가짜 샘플**로 화면을 만든다
   - 글은 전부 지어낸 `[샘플]` 문장이다(나인구 원문 아님). 가격만 실제 2024-10-15·16 BTCUSDT 1분봉 시가라 마커가 봉 위에 앉는다.
   - 일부러 넣은 경우: 줄바꿈 있는 글 · 사진 메시지 · 정정(reduce 덮어쓰기, `corrected_by`) · 계획(`plans`) · 불타기(`add`) · 「리스크 0%」 스탑 · 종료 없이 다음 진입(`unclosed`, `confidence: low`) · flags.
   - 진짜 데이터는 로컬 장부 세션이 만들어 `data/posts.enc` · `data/trades.enc`(암호화)로만 들어온다.

`docs/01_장부_작업지시.md`는 로컬 장부 세션용이다(참고만).
설계 문서의 정본은 브루스 PC의 매매 볼트(`BRUCE-TRADING\관점방\설계\`)다 — 바뀌면 여기로 다시 복사한다.
