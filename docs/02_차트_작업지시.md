## 1. 바꿀 것 · 더할 것

### 1-1. 시세 — 실시간 제거, 고정 데이터로
- 웹소켓·REST 호출 **제거**. 헤더의 실시간 가격 점(`connDot`·`livePrice`)은 「관점방 리플레이 · 2022-01 ~ 2024-12-06」 같은 고정 표기로 바꾼다.
- 범위 **2022-01-01 00:00 KST ~ 2024-12-06 23:59 KST**(관점방 내보내기 시각까지). 그 뒤 봉은 없다.
- 봉 간격 **1m 추가** → `1m · 5m · 15m · 1h` (원하면 4h). **1분봉이 원천**, 나머지는 빌드 때 미리 합쳐 둔다(브라우저 부담↓).
- 「최신으로(L)」 = 2024-12-06 마지막 봉. 날짜 이동 입력의 `max`도 그 날.

### 1-2. 데이터 파이프라인 — `tools/build_klines.py` (사이트 밖, 저장소에 같이 둬도 됨)
- data.binance.vision `spot/monthly/klines/BTCUSDT/1m/BTCUSDT-1m-YYYY-MM.zip` (2022-01 ~ 2024-11) + `daily/…/2024-12-01 ~ 06`.
  캐시 `관점방\_cache\` — **장부 세션과 공유**.
  ⚠ 2025년부터 아카이브 시각이 마이크로초로 바뀐 적이 있다 — 이 범위(~2024)는 밀리초지만, 자릿수로 판별하는 코드를 둔다.
- 출력 `site/data/klines/{1m,5m,15m,1h}/YYYY-MM.bin` — **월 단위 쪼개기**, 보이는 범위 근처만 늦게 불러온다(lazy).
  - 형식(권장): 봉마다 `Int32 t(분 단위 epoch)` + `Float32 o,h,l,c` = 20바이트. 1분봉 한 달 ≈ 44,640봉 ≈ 0.9MB (Pages가 gzip으로 보냄).
    합계 1분봉 36개월 ≈ 31MB + 상위 간격 수 MB. JSON보다 작고 파싱이 빠르다. (가격 소수 둘째 자리까지면 Float32로 충분 — 넘으면 Int32×100.)
  - `site/data/klines/index.json` — 간격별 월 목록·첫/끝 시각.
- 차트 쪽: `app.js`의 `fetchKlines()`를 「월 파일 읽기」로 갈아끼운다. 스크롤로 왼쪽 끝에 가면 이전 달 파일을 불러 붙이는 지금 구조(`subscribeVisibleLogicalRangeChange`)를 그대로 살린다.

### 1-3. 관점 패널 (posts.json)
- 차트 옆(가로 화면) / 아래 서랍(세로·폰)에 **관점방 타임라인** — 메시지를 시간순으로, `kind`별 색(signal·risk·view·routine).
- 메시지 탭 → 차트가 그 시각으로 이동 + 세로 점선. 반대로 차트를 움직이면 패널이 그 시각 근처로 따라간다(끄기 가능).
- 필터: `view`(사고과정·관점)만 보기 · 신호만 보기 · 전부. 검색창(본문 글자 검색).
- 사진 메시지는 「📷 사진(내보내기에 없음)」으로.
- **원문 그대로 표시**(줄바꿈 유지). 페이지가 문장을 고치거나 요약하지 않는다.

### 1-4. 매매 마커 (trades.json)
- 진입 ▲/▼(롱 초록·숏 빨강) · 청산 ✕ · 분할 정리 점(비율 라벨) · 불타기 ＋.
- **스탑선은 계단**: 스탑이 설정·이동된 시각부터 다음 이동(또는 청산)까지 수평 구간. 「리스크 0%」로 넘어간 칸은 색을 바꾼다.
- 마커 탭 → 그 사건의 원문 카드(`post` 연결) + 그 매매 요약(진입가·첫 스탑 거리·보유 시간·MFE/MAE·결과 %).
- 표시 켜기/끄기(그리기 도구 줄에 토글). 1h 이상에선 진입·청산만(겹침 방지).

### 1-5. 리플레이 — 이 사이트의 핵심
- **매매 목록**(날짜·롱/숏·결과·flags) → 하나 고르면 리플레이 시작.
- **블라인드**: 진입 시각 직전 봉까지만 그린다(그 뒤 봉·마커·글은 숨김). 화면에 「여기까지」 세로선.
  1. 브루스가 먼저 적는다 — 「들어갈까 / 방향 / 스탑 자리」(간단한 입력: 버튼 + 가격 탭으로 스탑선 찍기 + 한 줄 메모).
  2. 「다음 사건 열기」 → 그의 실제 사건(진입·스탑·정리·종료) 하나가 원문과 함께 열리고, 그 시각까지 봉이 늘어난다.
  3. 사건마다 다시 「나라면?」을 적을 수 있다(정리할까·스탑 올릴까).
  4. 끝나면 그의 전 과정과 브루스의 판단을 나란히 보여준다(일치/불일치 표시는 **같은 행동인가**만 — 잘잘못 판정 없음).
- 봉 단위 넘기기도 지원: ▶(1봉) · ▶▶(다음 사건까지) · 속도 조절 자동재생.
- 블라인드 끄기 = 전체 보기(공부용).

### 1-6. 브루스의 판단 저장
- 리플레이 입력·메모는 브라우저에 저장(원본과 같은 store 래퍼, 키 `nine9Replay.answers.v1`). **localStorage는 실패할 수 있다** — 원본처럼 try/catch.
- 기존 「그림 내보내기/가져오기」에 **리플레이 답 포함**(한 JSON). 기기 옮기기·백업용.
- 나중에 매매 볼트로 가져갈 수 있게 내보내기 JSON 형식을 `README.md`에 적는다(매매 볼트 `복기\`·`gaze training\`에서 쓸 수 있게).

### 1-7. 공개 범위 (공통설계 §6 — 브루스 결정 대기)
- 기본 구현은 **A안: `posts.json`·`trades.json`을 비밀번호로 암호화**해 `data/*.enc`로 올린다.
  - 암호화: 빌드 스크립트(`tools/encrypt_data.py`)가 PBKDF2(SHA-256, 반복 20만+) → AES-GCM. 브라우저는 WebCrypto로 푼다.
  - 첫 방문에 비번 입력 → 맞으면 풀어서 쓰고, 기기 기억(선택). 틀리면 차트만 보인다(봉은 공개 데이터라 그대로).
  - **비번 자체는 저장소·코드·문서 어디에도 쓰지 않는다.** 브루스가 정해서 빌드 때만 입력.
- B안(가져오기 전용)도 같은 코드로: 암호 파일이 없으면 「파일 가져오기」 버튼만 보인다.
- 원문 평문 JSON은 `.gitignore`(`data/posts.json`·`data/trades.json`) — 실수로 올라가지 않게.

### 1-8. 폰
- 원본처럼 홈 화면 추가(manifest)·와이드 모드 유지. 관점 패널은 세로에선 아래 서랍.
- 1분봉 한 달 파일 ≈ 1MB — 폰에서도 무리 없지만, 1m는 **보이는 달 ±1달만** 메모리에 둔다.

## 2. 순서

1. 원본 복제 → `site\`에 그대로 띄워 보기(로컬 `python -m http.server`).
2. `build_klines.py` → 월 파일 → 실시간 걷어내고 고정 데이터로 → 1m 추가. **여기까지는 장부와 무관하게 먼저.**
3. 장부 세션의 `posts.json` 초안이 나오면 관점 패널(1-3).
4. `trades.json`이 나오면 마커(1-4) → 리플레이(1-5·1-6).
5. 공개 범위 결정대로 암호화(1-7) → 브루스가 새 저장소 만들고 push → Pages.
6. `README.md`(데이터 갱신 방법·빌드 명령·내보내기 형식) + `관점방\진행.md`에 한 줄.
